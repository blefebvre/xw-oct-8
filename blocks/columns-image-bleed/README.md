# columns-image-bleed

Custom **columns** block. Purpose: A photo that bleeds to the left viewport edge beside one vertically centred text column.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 2 columns x 1 row: image cell (the photo alone), rich-text cell. If the image is authored in the second cell it bleeds to the right edge instead.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
