# cards-download

Custom **cards** block. Purpose: Grid of downloadable document tiles, each a centred title with a DOWNLOAD button, inside one elevated white card.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Cards (no images): one row per document with a single rich-text cell (UE field text): title paragraph(s), then a paragraph holding only the DOWNLOAD link to the PDF.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
