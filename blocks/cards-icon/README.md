# cards-icon

Custom **cards** block. Purpose: Grid of separate elevated white cards, each led by a small centred icon, with a heading, optional description and a single call-to-action button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Cards with images: one row per card with two cells (UE fields image + imageAlt, then rich text). Cell 1: the icon image. Cell 2: heading, optional description paragraph(s), then a paragraph holding only the call-to-action link.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
