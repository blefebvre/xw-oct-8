# hero-banner

Custom **hero** block. Purpose: Full-width photo page-title banner that opens an inner page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = background image (UE fields image + imageAlt); row 2 = rich text (UE field text) with the page title as H1 and an optional subtitle paragraph.

## Supported variations

| Variation | Option class |
| --- | --- |
| Left aligned | `left` |

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- `classes` select for options: Left aligned.
