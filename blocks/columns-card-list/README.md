# columns-card-list

Custom **columns** block. Purpose: Side-by-side lists of short dated items inside a centred white elevated card.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one rich-text cell per column; each paragraph is one item: date, line break, bold name.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
