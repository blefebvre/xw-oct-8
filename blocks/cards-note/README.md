# cards-note

Custom **cards** block. Purpose: Separate white shadowed text note cards with a red-to-purple gradient bar on the left edge, optionally led by a small icon.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per card. Text-only card: one rich-text cell (in UE the unset icon field leaves an empty first cell, which is dropped). Icon card: two cells, the icon image (UE fields image + imageAlt) then rich text.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
