# accordion-tips

Custom **accordion** block. Purpose: Expandable tip panels shown as separate white shadowed cards, each title optionally led by an icon and followed by a chevron; first item open.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per item with cells: label (UE field summary), body rich text (field text), then an optional icon image (fields image + imageAlt). Rows with only label and body render without an icon.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
