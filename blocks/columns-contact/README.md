# columns-contact

Custom **columns** block. Purpose: Contact details laid out beside a full-height photo, with a note card under the text columns.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 3 columns x 2 rows. Row 1: image cell, rich-text cell, rich-text cell. Row 2: empty cell under the image (photo spans it), note rich-text cell, empty cell (note widens across both text columns).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
