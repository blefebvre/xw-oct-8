# hero-promo

Custom **hero** block. Purpose: Medium-height full-bleed photo background with a darkening overlay and left-aligned heading, paragraph and CTA.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = background image (UE fields image + imageAlt); row 2 = rich text (UE field text) with heading, paragraph and a CTA link.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
